# Audit OTTY's Current Product Truth

Type: research
Status: resolved
Blocked by: none

## Question

What evidence-backed inventory of OTTY's implemented Current Capabilities, in-development behavior, supported platforms, release maturity, existing release mechanics, and reusable Product Evidence can be established from the `otty` repository, and which product claims can the website and Documentation truthfully make today?

## Answer

Research asset: branch `research/otty-current-product-truth`, commit `b01881dfdce955410d752b7fd2580405b207b964`, path `docs/research/otty-current-product-truth.md`.

OTTY can currently be presented as an early, open-source, terminal-centric workspace with tabs, split panes, Bash/Zsh command blocks, file-aware Explorer behavior, saved local launches, and a limited SSH path. Public content must distinguish capabilities available in the latest Published Release, behavior implemented only on `main`, and Product Vision. Operational Hub, Kubernetes/lab orchestration, “true IDE,” and replacement of a full SSH client are not supportable current claims.

The existing screenshots are useful references but not a coherent launch-ready evidence set. Product content must disclose shell integration boundaries, exact supported package targets, early-release maturity, and SSH limitations. Application-side SSH security and launch-boundary work remains outside this website map.
