# OTTY web visual language prototype

Throwaway prototype for the decision in “Establish OTTY's Web Visual Language.” It does not implement the production Astro/Starlight site, and the repeated product screenshot is a local placeholder rather than launch-ready Product Evidence.

Run from the website repository root:

```sh
python prototypes/web-visual-language/serve.py
```

Open <http://127.0.0.1:4173/prototypes/web-visual-language/?variant=A>. Use the floating bar or the left/right arrow keys to switch between:

- `A` — Signal Ledger
- `B` — Open Canvas
- `C` — Operator Rail
- `D` — Signal Sequence: the selected A direction with terminal typography and an accessible auto-advancing capability slider controlled by four labeled tabs
- `E` — Signal Matrix: the selected A direction with terminal typography and a static capability grid

The Landing, Docs, and Install controls show how each direction extends across the custom Product Landing, Starlight Documentation, and `<LatestDownloads />`.
